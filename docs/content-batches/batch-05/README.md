# Content Production Batch 05 v0.1

Twelve CMS-ready draft lessons: K1-L15–L18, Y1-L15–L18, and T1-L15–L18.

All records are `in_review`. Schema compliance does not equal publication approval. Complete exegetical, developmental, pastoral (where required), and copy review before scheduling.

## Import
Copy `repo_import/src/content/` into the corresponding repository content directory, run the existing validator and build, then inspect Teacher and Family routes in a Netlify Deploy Preview.

## Important review boundaries
- Food insecurity and scarcity must not be framed as proof of weak faith.
- Hannah's prayer must not become a promise that every requested outcome is granted.
- Exile must not be mapped onto modern victims as proof of hidden guilt.
- Intertestamental and Second Temple historical claims require source verification.
- Gospel differences require passage-level analysis rather than automatic harmonization or contradiction claims.
- Kingdom language must not be collapsed into a modern political program.
