# Content Production Batch 01 v0.1

## Scope

This pack contains six complete, schema-v1.2 lesson records:

- K1-L01 — God Made a Good World
- K1-L02 — People Bear God's Image
- Y1-L01 — A Library That Tells One Story
- Y1-L02 — Creation and God's Good Rule
- T1-L01 — Why Study Scripture This Way?
- T1-L02 — What Christians Mean by Scripture

It also contains six printable/resource source records and Markdown review renderings.

## Status

All records are `in_review`. They passed JSON Schema, canonical identity, timing, family-flow, reference-resolution, and resource-resolution checks. They are not yet publication-approved.

## Import into the web repository

1. Copy JSON files from `lessons/` into the matching `src/content/lessons/<segment>/` directories.
2. Copy resource JSON files from `resources/` into `src/content/resources/`.
3. Run the repository's content validator and build.
4. Review the Deploy Preview in both Teacher and Family routes.
5. Complete exegetical, developmental, and copy review before changing status to `approved`.
