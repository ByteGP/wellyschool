# Content Production Batch 02 v0.1

## Scope

This pack contains twelve complete, schema-v1.2 lesson records:

### Kids
- K1-L03 — People Disobey God
- K1-L04 — God Promises to Put Things Right
- K1-L05 — God Cares for Noah
- K1-L06 — God Calls Abraham

### Youths
- Y1-L03 — Human Rebellion and Its Spread
- Y1-L04 — Noah: Judgment, Mercy, and Covenant
- Y1-L05 — Abraham and Blessing for the Nations
- Y1-L06 — Joseph and Providence

### Teens
- T1-L03 — Canon, Ancient Sources, and Authority
- T1-L04 — Translation, Manuscripts, and Humility
- T1-L05 — Creation, Order, and the Image of God
- T1-L06 — The Fall and the Logic of Idolatry

It also contains twelve printable/resource source records and Markdown review renderings.

## Status

All records are `in_review`. They passed JSON Schema, canonical identity, timing, family-flow, reference-resolution, and resource-resolution checks. They are not publication-approved.

The canon-history and textual-criticism claims in T1-L03 and T1-L04 are deliberately marked for source review. This batch does not treat unsourced historical assertions as finished curriculum.

## Import into the web repository

1. Copy JSON files from `lessons/` into the matching `src/content/lessons/<segment>/` directories.
2. Copy resource JSON files from `resources/` into `src/content/resources/`.
3. Run the repository content validator and build.
4. Review the Deploy Preview in both Teacher and Family routes.
5. Complete exegetical, developmental, pastoral where flagged, and copy review before changing status to `approved`.

## Review priorities

- K1-L03: avoid shame, public confession, and blaming Eve alone.
- K1-L04: keep Genesis 3:15 distinct from later canonical synthesis; do not claim the verse contains the entire gospel explicitly.
- K1-L05: preserve judgment without graphic fear or modern-disaster blame.
- K1-L06: reject prosperity readings and keep blessing oriented toward others.
- Y1-L03: distinguish strong emotion from violent action and use fictional cases only.
- Y1-L04: hold judgment, preservation, and covenant together; avoid scientific or disaster overclaims.
- Y1-L05: present election as mission rather than superiority and distinguish Genesis from Galatians.
- Y1-L06: providence must not excuse harm, force reconciliation, or erase accountability.
- T1-L03: exact canon-boundary claims require historical evidence beyond Luke 24 and Romans 3.
- T1-L04: externally verify every manuscript example before publication; avoid both denial and panic.
- T1-L05: image-of-God language must be disability-inclusive; creation models remain non-salvific.
- T1-L06: teach Romans 1 within Paul’s universal argument and never weaponise it against one group.
