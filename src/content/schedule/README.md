# Schedule entries

One JSON file per date and segment, created through Decap CMS.
Filename pattern: `YYYY-MM-DD-segment.json`.

Scheduling policy (owner, 2026-08-12): classes run on Sundays during Wellington
school terms; term-holiday Sundays are `break` entries. If a special day such as
Father's Day falls inside a school term, kids classes run as normal. The
committed entries are draft placeholders for the pilot; enter the approved
church calendar through Decap and set entries to `approved` for production.
